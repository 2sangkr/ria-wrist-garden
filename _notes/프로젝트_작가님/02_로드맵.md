# 작가님 — 개발 로드맵

## 1단계: MVP ⏳ 기획 중

**목표:** "가장 편한 업로드 + 가장 예쁜 전시" 두 가지만 확실히

> 참고: 아트소니아(Artsonia)는 미국 어린이 미술 포트폴리오 서비스. 우리는 한국 정서에 맞게 로컬라이징.

### 1-1. 작가님 대접 UI (최우선)
- [ ] 작품 아래 **[작가 노트]** 섹션 — 부모가 아이 한마디 대신 입력
  - 예: "이건 공룡이 아니라 춤추는 구름이에요!"
- [ ] "이번 주 신작 등록하기" 같은 감성 표현 사용 (Upload 대신)
- [ ] 나이/학년별 성장사 시각화 (현재 MVP 사이트에 구현 완료)

### 1-2. 지인 공유 (2순위)
- [ ] **카톡 단톡방 공유 버튼** — 예쁜 카드 형태로 가족 단톡방에 뿌리기
- [ ] 카카오 OG 이미지 최적화 (썸네일 잘 뜨게)
- [ ] 공유 시 "Hee 작가님의 신작이 도착했습니다!" 문구 자동 생성

### 1-3. 칭찬 배지 (3순위)
- [ ] 방명록 대신 **칭찬 스티커** — "엄지 척", "색감이 예뻐요", "창의력 대단해요"
- [ ] 칭찬 수 카운터 표시 → 아이가 성취감 느끼게

### 기타 MVP 항목
- [ ] 기술 스택 결정 (Flutter vs React Native)
- [ ] Firebase / Supabase 선택
- [ ] 학원 선생님 학생 관리 기능
- [ ] 학부모 앱 뷰 (자녀 작품 보기)
- [ ] 기본 알림 (작품 등록 시 학부모 푸시)

**완료 기준:** 미술학원 1곳에서 실제 파일럿 운영 가능
