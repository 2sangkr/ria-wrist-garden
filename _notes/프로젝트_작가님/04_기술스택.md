## 데이터 구조

```
Users: uid, name, role, academy_id, profile_img
Artworks: id, user_id, img_url, title, description, timestamp
Galleries: user_id, theme_id, objects_layout_json
Academies: id, name, manager_uid, student_uids
```

## 외부 API

- POD(주문제작) 업체 API — 포토북/굿즈 제작
- 푸시 알림 — Firebase Cloud Messaging (FCM)
- 결제 — 토스페이먼츠 (손목정원과 동일)
