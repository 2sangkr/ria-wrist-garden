# 작가님 (Jakganim) — 프로젝트 개요

## 비전
> 아이들의 예술적 성장을 기록하고, 학원과 가정을 연결하며,  
> 실물 굿즈(포토북)와 커머스로 확장되는 **어린이 예술 생태계**

## 핵심 가치

| 대상 | 가치 |
|------|------|
| 아이들 | "나도 작가다" — 자존감 + 나만의 갤러리 공간 |
| 학부모 | 자녀의 예술적 연대기를 디지털/실물로 소장 |
| 미술학원 | 디지털 포트폴리오 시스템으로 차별화 마케팅 |

## 현재 상태
- 기획 단계 (문서화 진행 중)
- 기술 스택 미확정 (Flutter vs React Native 결정 필요)

## 두 프로젝트 연계 가능성

손목정원의 "초등학생 작가" 스토리 ↔ 작가님의 "어린이 갤러리"  
→ 작가님 갤러리에서 손목정원 굿즈로 연결되는 시나리오 고려 가능
