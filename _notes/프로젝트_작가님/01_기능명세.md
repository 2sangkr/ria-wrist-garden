# 작가님 — 기능 명세

## A. 작가 모드 (학생 / 학부모)

### 디지털 아카이브
- 작품 업로드: 제목 + 설명 + 날짜
- 작품 10개 이상 시 → 정식 갤러리 활성화

### 커스터마이징 갤러리 (싸이월드 방식)
- [ ] 배경 스킨 선택
- [ ] BGM 설정
- [ ] 아바타 꾸미기
- [ ] 가구 배치 (Drag & Drop)
- [ ] 자이로스코프 3D 뷰 (모바일 기울이기)

### 포토북 빌더
- [ ] 갤러리 테마 자동 반영
- [ ] 레이아웃 자동 생성
- [ ] 온라인 주문 제작 (POD API 연동)

### 커뮤니티
- [ ] 방명록
- [ ] 칭찬 스티커 보내기

---

## B. 매니저 모드 (미술학원 선생님)

### 학생 관리
- [ ] 반별 / 연령별 학생 목록
- [ ] 작품 현황 대시보드

### 대리 업로드
- [ ] 수업 현장 사진 촬영
- [ ] 해당 학생 프로필로 즉시 전송

### 알림
- [ ] 작품 등록 시 학부모에게 실시간 푸시 알림

### 운영 툴
- [ ] 학원 단위 전시 앨범 생성
- [ ] 이벤트 관리

---

## 우선순위 (MVP 기준)

MVP에 반드시 들어가야 할 것:
1. 작품 업로드 + 리스트 뷰
2. 학원 선생님 대시보드
3. 학부모 푸시 알림

MVP에서 제외 (2단계 이후):
- 갤러리 꾸미기 (스킨, 가구 배치)
- 포토북 빌더
- 커뮤니티 기능
