## 1. 글로벌 3사 개요

### 1-1. Artsonia

- 설립: 2000년 / 본사: 일리노이주 거니 (Gurnee, IL)
- 규모: 직원 11~50명 / 연매출 약 $2.2M (약 30억원)
- 누적 작품: 1억 3,500만+ 점 (연간 1,000만 점 신규)
- 이용 학교: 미국 내 50,000개+ K-12 학교 / 100개국 이상
- 핵심 정체성: 세계 최대 학생 디지털 포트폴리오 플랫폼
- URL: https://www.artsonia.com

**비즈니스 모델**
- 플랫폼 자체는 완전 무료 (교사·학생·학부모 모두)
- 수익: 학생 아트워크 인쇄 굿즈 판매
- 매출의 20%를 해당 학교 미술 프로그램에 기부

**주요 굿즈 가격대**

| 상품 | 가격 |
|------|------|
| 마그넷 | $7.95 |
| 아트 프린트 | $8.95+ |
| 티셔츠 | $16.95+ |
| 머그컵 | $15.95+ |
| 캔버스 아트 | $39.95+ |

**핵심 기능**
- 교사가 학급 포털 개설 → 학생 작품 업로드 → 교사 심사 후 게시
- 부모에게 새 작품 알림 발송
- Artist of the Week (주간 베스트 작품 선정)
- 학교 단위 마일스톤 어워드
- 아티스트 스테이트먼트 작성 기능
- 자체 라이트박스 하드웨어 판매 ($99/$139)
- COPPA·FERPA 규정 준수, iKeepSafe 인증

> **핵심 강점**: 연중 운영 → 작품이 쌓일수록 이탈 불가능한 락인 구조

### 1-2. Square 1 Art

- 설립: 25년+ / 본사: 조지아주 Norcross
- 누적 학교 환원액: $4,700만+ (올해 목표 $600만)
- 핵심 정체성: 학교 펀드레이저(모금 행사) 전문 대행사
- URL: https://www.square1art.com

**비즈니스 모델**
- 연 1~2회 이벤트성 캠페인으로 운영
- 학교 코디네이터가 펀드레이저 신청 → 학생 작품으로 굿즈 제작 → 부모 구매 → 수익 일부 학교 지급
- 아트 액세스 코드 1개로 모든 가족 참여 가능

> **핵심 강점**: 코디네이터 1명이 운영 가능한 극도의 단순함

### 1-3. Art to Remember

- 설립: 1995년 / 본사: 인디애나폴리스
- 직원: 45명 + 시즌 추가 인력
- 누적 미술 교육 환원: $3,000만+
- 핵심 정체성: 풀서비스 학교 펀드레이저 대행사
- URL: https://arttoremember.com

**비즈니스 모델**
- 학교 수익 기본 25%, 최대 38% 지급 (3사 중 최고 환원율)
- 작품 수거 → 자체 스캔 → 개인 주문서 생성 → 배송까지 완전 대행
- 초기 비용 제로, 학교 부담 최소화
- 디지털 갤러리 기능도 부가 제공

> **핵심 강점**: 학교 입장에서 할 일이 거의 없는 풀서비스 → 재계약률 높음

## 3. 모모갤러리 현황 분석

- URL: https://ria-wrist-garden.vercel.app
- 슬로건: "모든 아이의 모든 예술"
- 핵심 카피: "우리 아이가 만든 것들, 박스 속으로 사라지기 전에 이곳에 남겨두세요"
- 현재 작가 수: 3명 (D.hee, James, Emma)
- 작품 장르: 그림, 핸드메이드, 레고 등 포용
- 개발 스택: Next.js / Vercel 배포
- 현재 단계: MVP 완성

**잘 된 것들**
- 페인포인트를 정확히 찌르는 감성 카피
- 저작권 명시 ("각 작품을 만든 어린이 작가에게")
- 그림 외 핸드메이드·레고까지 포용하는 넓은 정의

**개선 필요 사항**
- 작가 수 부족 (3명) → 신뢰도 저하
- 참여 창구가 구글폼 → 인앱 플로우로 전환 필요
- 학원/학교 B2B 진입점 없음
- 작품 개별 공유 카드 (인스타 최적화) 없음
- 좋아요·댓글 등 참여 장치 부재

## 4. 모모갤러리 포지셔닝

> Artsonia의 "갤러리 플랫폼" 구조  
> + Art to Remember의 "학원 수익 환원" 인센티브  
> + 한국 특화 (카카오 + AI + 입시 포트폴리오)

**3사에 없는 모모갤러리 차별화 기회**

| 공백 영역 | 모모갤러리 기회 |
|-----------|----------------|
| AI 기능 전무 | AI 작품 코멘트, 성장 리포트 자동 생성 |
| 입시 포트폴리오 없음 | 중고등 미술 입시 특화 PDF 포트폴리오 |
| 카카오 연동 없음 | 한국 학부모 접점 = 카카오톡 |
| 영어 전용 | 한국어 자체가 진입장벽 제거 |

## 5. 유저 확보 전략

**핵심 원칙: B2B2C**
> 미술학원 원장 1명 = 학생 30~100명 자동 확보  
> 개별 학부모 직접 공략 시 CAC(고객획득비용)이 너무 높음

### Phase 1 — 첫 100개 학원 확보

타겟: 수도권 사설 미술학원 원장

원장 페인포인트
- 학부모 소통이 카카오 단톡방 의존 → 관리 어려움
- 작품 사진을 매번 찍어 개별 전송
- 포트폴리오 정리 = 수작업

실행 방법
- 네이버 지도 "미술학원" 검색 → 원장 번호로 카카오 메시지 발송
- 처음 20개 학원 무료 + 직접 세팅 지원
- 네이버 카페 "미술학원 원장 모임" 커뮤니티 침투
- 미술학원 인스타 계정에 DM 영업

### Phase 2 — 바이럴 루프 설계

```
학원 등록
  → 작품 업로드 시 학부모 카카오톡 자동 알림
  → 부모가 갤러리 링크를 조부모·친척에게 공유
  → 공유 링크에 "모모갤러리로 만들었어요" 워터마크
  → 신규 학원 문의 유입
```

MVP+1 추가 기능 (우선순위)
1. 작품 카드 자동 생성 (인스타 공유용 1:1 비율 이미지)
2. "이 갤러리는 모모갤러리로 제작되었습니다" 푸터 링크
3. 학부모용 카카오 알림톡 연동

### Phase 3 — 수익화

**학원 수익 환원 모델 (ATR 벤치마킹)**
> 학생 작품 → 굿즈 판매 → 수익 일부를 학원에 리베이트  
> 원장이 "모모갤러리 쓰면 우리 학원에 돈이 들어온다"고 인식하면 자발적 영업사원이 됨

**한국형 굿즈 라인업**

| 상품 | 특이사항 |
|------|----------|
| 포토북 | 한국 부모 선호도 1위 |
| 아크릴 액자 | 고급감, 선물용 |
| 에코백 | 저가, 일상 사용 |
| 텀블러 | 어버이날·졸업 시즌 |

**수익 모델 옵션**
- 굿즈 커머스: POD(주문형 인쇄) 연동 → 재고 없이 운영
- 프리미엄 갤러리: 학원 월정액 (커스터마이징, 도메인 등)
- 디지털 포트폴리오 PDF: 유료 다운로드 (입시용)

## 결론

> 3사가 25~30년에 걸쳐 각자 발견한 것들을 모모갤러리는 처음부터 통합 설계할 수 있는 위치에 있다.  
> 가장 빠른 실행은 **미술학원 원장에게 수익 환원 구조를 먼저 제시**하는 것 — 원장이 영업사원이 되는 순간 유저 확보 속도가 달라진다.
