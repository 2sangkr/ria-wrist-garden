## 주요 기능

### 공개 기능
- **작가 갤러리**: 나이별/연도별 그룹핑, 이미지 그리드
- **작품 상세**: 이미지, 제목, 날짜(나이·연도), 재료, 작가 정보
- **카카오톡 공유**: Kakao SDK 연동, 인앱 브라우저에서 카카오톡으로 공유
- **URL 복사/네이티브 공유**: 카카오 미지원 환경 폴백
- **작가 등록 문의**: 구글폼 링크 연결

### 어드민 기능 (`/admin`)
- 비밀번호 로그인 (쿠키 기반 세션)
- 작가별 작품 목록 확인
- 작품 추가 (제목, 날짜, 나이, 재료, 이미지 업로드)
- 작품 삭제 (이미지 파일도 함께 삭제)
- 이미지 → Supabase Storage 자동 업로드

## Supabase DB 구조

### artists 테이블
```
id (text PK), slug, name, tags (text[]), bio,
profile_color, is_empty (bool), sort_order
```

### works 테이블
```
id (serial PK), artist_id (FK → artists.id),
slug, title, image, materials (text[]),
created_at (date), age (int)
```

### 권한 설정
- `GRANT SELECT ON artists TO anon;`
- `GRANT SELECT ON works TO anon;`
- RLS policy: public_read_artists, public_read_works (SELECT TO anon USING (true))
- 쓰기는 service_role key만 가능 (어드민 API에서 사용)
