## 명령어 목록

| 명령어 | 설명 |
|--------|------|
| `/start` | 시작 메시지 |
| `/help` | 명령어 목록 |
| `/stats` | 현재 현황 (방문수, 작가, 작품, 좋아요) |
| `/brief` | /stats와 동일 |
| `/top` | 좋아요 TOP 3 작품 |
| `/artists` | 등록 작가 전체 목록 + 작품 수 |
| `/artist [이름]` | 특정 작가 정보 + 업로드 링크 |
| `/link [slug]` | 업로드 링크 생성 (예: `/link dhee`) |

## 업로드 알림 설정 (미완료)

새 작품 업로드 시 즉시 알림을 받으려면 Supabase에서 Database Webhook 설정 필요.

**설정 방법:**
1. Supabase → Database → Webhooks → Create Webhook
2. 이름: `works_insert_notify`
3. 테이블: `works`
4. 이벤트: `INSERT`
5. URL: `https://mymomo.gallery/api/notify/upload`
6. HTTP Headers 추가:
   - `x-webhook-secret`: `gallery2026`
